# 🎴 Cards Hub (Client Only)

**Cards Hub Client** is the frontend application for **Cards Hub**, an online platform for playing a variety of card games with friends or other players worldwide — all from your browser.

> This requires the [backend](https://github.com/Tiago-0liveira/cards-hub-server/) running to fully work


![Cards Hub Screenshot](https://github.com/user-attachments/assets/66e18a48-3f76-4fb2-84d6-0122f95ae767)


---

## 🌟 Features

- 🕹️ Play a variety of card games online (for now just one game is available)
- 👥 Real-time multiplayer support via WebSockets
- 🎨 Responsive and interactive UI optimized for desktop
- 🚪 Create or join game rooms with unique names
- 🚀 Fast and smooth gameplay experience

---

## 🔧 Tech Stack

- React — UI library
- React Router — Client-side routing
- Socket.io — Real-time multiplayer communication
- Tailwind CSS — Modern styling
- Vite — Bundler for fast builds and dev server

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v14+)
- npm or anything you want

### Installation

```bash
git clone https://github.com/Tiago-0liveira/cards-hub-client.git
cd cards-hub-client
npm install
```

#### Create a `.env`

```env
VITE_SERVER_ENDPOINT=http://localhost:3000
```
#### Start dev server
```bash
npm run dev
```
